# Tableau Data Analytics Projects

A collection of interactive Tableau projects demonstrating data visualization, dashboard development, business analysis, and storytelling.

## 📊 Projects

### 1. HR Workforce & Employee Attrition Analysis

An interactive HR analytics dashboard analyzing workforce composition, employee termination patterns, performance, termination reasons, recruitment sources, and monthly termination trends.

**Dataset:** 311 employees  
**Tools:** Tableau, Excel

**Key Analysis:**
- Workforce overview
- Active vs terminated employees
- Department-level termination rates
- Performance and termination patterns
- Termination reasons
- Recruitment source analysis
- Monthly termination trends
- Interactive dashboard filters

📁 [View HR Workforce & Employee Attrition Analysis](./HR-Workforce-Attrition-Analysis/)
